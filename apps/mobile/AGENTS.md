# Mobile package

Follow the repository rules in `/AGENTS.md` and `/.cursor/rules/`.

This package is Expo SDK 58. Before using an Expo, EAS, or React Native API, read the matching versioned page under `https://docs.expo.dev/versions/v58.0.0/`. The index of current docs is `https://docs.expo.dev/llms.txt`.

Install libraries with `npx expo install`. Do not create `ios/` or `android/` by hand.
